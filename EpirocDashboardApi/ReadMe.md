# Epiroc Dashboard API (Backend)

This is a .NET Web API that powers the Epiroc Vehicle Dashboard.
It provides real-time vehicle data and supports user interactions such as speed control and charging simulation.
The backend is designed to simulate a dynamic system where telemetry values continuously change and are persisted in a database.

## API Endpoints

### Get Dashboard Data

GET /api/dashboard

Returns current dashboard state:

* RPM
* Speed
* Battery %
* Temperature
* Power
* Indicators
* GearRatio
* IsCharging
* EngineCheck
---

### Update Speed

POST /api/dashboard/speed

Request Body:

```json
{
  "speed": 50
}
```

---

### Toggle Charging

POST /api/dashboard/charge

Toggles charging state of the battery.

## Background Simulation Service

The application includes a background worker service that simulates real-time vehicle behavior.

This service runs continuously and updates dashboard values every 2 seconds.

### Implementation

Implemented using .NET `BackgroundService`.

### Simulation Logic

* **Motor RPM**

  * Calculated based on speed
  * `RPM = Speed × 30`

* **Battery Behavior**

  * Increases when charging is ON
  * Decreases when charging is OFF
  * Clamped between 0% and 100%

* **Temperature**

  * Based on motor activity
  * `Temperature = 30 + (RPM / 100)`

* **Power**

  * Derived from speed
  * `Power = Speed × 2`

### Update Frequency

* Runs every **2 seconds**
* Updates are persisted to MongoDB
* Frontend reflects these updates in near real-time

---

## Database

* MongoDB Atlas (cloud-hosted)
* Stores dashboard state in a collection
* `_id` is auto-generated by MongoDB
* Data is continuously updated by simulation service
